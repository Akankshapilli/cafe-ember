## Overview

**Café Ember** is a premium café and lifestyle brand website built around cinematic storytelling, immersive branding, and conversion-focused user journeys. The project goes beyond a typical restaurant site — it's a full digital brand experience designed to evoke atmosphere, emotion, and desire before a customer ever walks through the door.

Designed and developed independently — covering UX strategy, visual identity, interface design, and responsive frontend implementation.

---

## Design Philosophy

> *"A café experience that starts online."*

Every design decision — typography, colour, motion, layout — serves the brand story. Café Ember is warm, editorial, and premium. The digital experience mirrors the physical one: unhurried, atmospheric, and memorable.

---

## Features

- 🎬 **Cinematic Hero** — Full-screen immersive entrance with Framer Motion animations
- 🎨 **Brand Identity** — Custom visual identity system: palette, typography, iconography
- 📖 **Storytelling Layout** — Editorial scroll sections that narrate the brand story
- ✨ **Micro-interactions** — Subtle hover states, reveals, and transitions throughout
- 📱 **Mobile-First** — Fully responsive with touch-optimised interactions
- 🛒 **Conversion Focus** — Menu, reservations, and CTAs designed for action
- 🖼️ **Immersive Visuals** — Full-bleed imagery with scroll-triggered parallax effects

```bash
cd cafe-ember
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.
